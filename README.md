# Inflatable Cutter — раскрой плоской надувной фигуры

Вход: векторный PDF-макет (перёд+зад+рука разнесены). Выход: лекала (перёд, зад, боковины,
днище, ножка) в PDF/SVG. Linux, без GUI, без CorelDRAW/Blender.

## Запуск
    python main.py examples/cosmonaut_2700.pdf --config config.yaml     # перёд/зад: контур+обтравка
    python sides_stage.py examples/arm_sep.pdf --config config.yaml     # боковины+днище+ножка, раскладка
    python -m pytest tests/ -q

## Что реализовано
- **Перёд/зад:** векторный контур по краям макета (union заливок) → масштаб к 2700 мм →
  обтравка оригинального вектора по контуру (PowerClip, `W n`) + линия реза.
- **Боковины (гассет)** — `src/sides.py`:
  - длина = периметр контура переда − днище; инвариант `Σ длин полос = периметр − днище`;
  - **толщина по частям от вентилятора:** 1-я деталь у низа = 460 (оба конца), переход,
    корпус/голова = 350;
  - **симметрия низа:** 1-я деталь = `max(угол_лево, угол_право)` (одинаково Л/П),
    2-я деталь (переход 460→350) = `transition_piece_len_mm` (500), одинаково Л/П;
  - **стыки — трапеции:** торцы соседей совпадают; боковое **ребро = длине дуги** переда;
  - **выступы (антенна и т.п.):** детект (opening + фильтр reach/R — только тонкие выпуклые,
    не углы панелей); ОДНА деталь-«песочные часы» (талия `tip_width`=250), длина ≥
    `protrusion_min_piece_mm` (500, иначе слить с соседями); высота под ребро = дуге;
  - раскладка: перёд в центре, боковины по своим сторонам, днище+ножка ниже, без нахлёста.
- **Днище + ножка** — `src/base.py`: днище = `нижняя_кромка × толщина` + красное отверстие
  Ø `fan_diameter`; ножка = `π·Ø × leg_height`.
