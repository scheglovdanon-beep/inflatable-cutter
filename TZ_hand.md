# ТЗ: деталь кисти и её стыковка с предплечьем

## Цель
Из уже детектированной и отрезанной кисти построить объёмную деталь-«печенье»
(перёд + зеркальный зад + боковина-прямоугольник) и состыковать её с предплечьем
по линии среза запястья так, чтобы периметр открытого края кисти точно совпал с
кромкой предплечья.

## Вход
- `hand_contour` (кисть) — замкнутый контур: кривая кромка `B→кончик→T` + прямая
  линия среза запястья `B–T`. (`out/hand_contour.json`)
- `forearm_contour` (предплечье) — замкнутый контур: кривая кромка `T→локоть→B` +
  та же прямая `B–T`. (`out/forearm_contour.json`)
- точки запястья `B`, `T` из `detect_wrist()`.
- масштаб в мм: `scale = fig.s * PT2MM` (как в `contour_to_mm`). **Кисть и предплечье
  меряются в ОДНОМ масштабе** (оба — вырезанные детали исходной руки). Шаблонную руку
  (`build_arm`, масштаб по Ø250) здесь НЕ использовать — другой масштаб.

## Замеры (в единицах контура, затем × scale → мм)
1. **Ровное ребро кисти** `straight` = |B − T| (длина прямого среза запястья).
2. **Кривая кромка кисти** `curved` = периметр(`hand_contour`) − `straight`
   (вся кривая часть силуэта кисти, без линии среза).
3. **Верхнее ребро предплечья** `fore_top`:
   - разбить `forearm_contour` на рёбра по углам (как `arm.measure_edges`,
     порог угла ≈28°, упрощение `corner_simplify_mm`);
   - из длинных рёбер взять то, у которого **меньше средний y** (верхнее) → его длина.
   (нижнее ребро — с бóльшим средним y; служит для проверки/справки.)

## Построение детали кисти («печенье»)
1. **Перёд** = `hand_contour`.
2. **Зад** = `hand_contour`, отзеркаленный **справа налево** (горизонтальный флип
   относительно вертикальной оси; `shapely.affinity.scale(xfact=-1)`), затем выровнять
   по bbox. Перёд и зад — зеркальные лепестки.
3. **Боковина (прямоугольник)** — скрепляет перёд и зад по кривой кромке:
   - **ширина** (толщина кисти):
     `W = (fore_top − 2 · straight) / 2`
   - **высота** (длина боковины):
     `H = curved`
   Длинные рёбра прямоугольника (длиной `H`) сшиваются с кривой кромкой переда и зада
   соответственно; короткие рёбра (длиной `W`) — это торцы у запястья.

## Стыковка с предплечьем (инвариант)
Открытый край кисти у запястья — замкнутая петля из:
`перёд.straight + боковина.W + зад.straight + боковина.W = 2·straight + 2·W`.
По построению `W`:
```
2·straight + 2·W = 2·straight + (fore_top − 2·straight) = fore_top
```
⇒ **периметр открытого края кисти == верхнее ребро предплечья** → детали сшиваются
без сборок/натяга. Это главный проверяемый инвариант.

## Инварианты (тесты)
- `W > 0` (требует `fore_top > 2·straight`; иначе — рассогласование масштаба/модели,
  выдать понятную ошибку, не строить).
- `2·straight + 2·W == fore_top` (Δ < 1 мм).
- длинное ребро боковины `H == curved` (Δ < 1 мм) и `== длине кривой кромки переда`
  и `== зада` (перёд/зад зеркальны, длины равны).

## Выход
- деталь кисти: 3 полигона — `front`, `back` (зеркальный), `gusset` (W×H), разложены
  без наложений; добавить в примерочную раскладку и экспорт (PDF/SVG), рядом с
  деталями руки.
- рендер-превью с подписями длин рёбер и результатом проверки инвариантов.

## Припуски / насечки (как в остальном проекте)
- припуск `seam_allowance_mm` добавить на сшиваемые кромки: кривые кромки переда/зада,
  длинные рёбра боковины, и петлю открытого края (торцы боковины + прямые срезы).
- насечки `notch_interval_mm` — опционально, на длинные швы боковины.

## Параметры (config.yaml)
- отдельных числовых параметров не вводим — всё выводится из геометрии кисти и
  предплечья. Используются существующие `seam_allowance_mm`, `notch_interval_mm`,
  `corner_simplify_mm`.
