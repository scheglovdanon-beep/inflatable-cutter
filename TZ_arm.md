# ТЗ для Claude Code — отделение машущей руки + контур/обтравка всех деталей

## Контекст
Продолжаем проект `/opt/inflatable-cutter` (Linux, без GUI, без CorelDRAW/Blender).
Уже готово и работает (не переписывать, переиспользовать):
- `src/read_pdf.py` — чтение вектора, отсев фона, разделение по X.
- `src/pieces.py` — контур: `union → buffer(+d).buffer(-d)` → один Polygon без дыр; масштаб.
- `src/export.py` — PDF-обтравка (clipping path `W n`) + слой линии реза, SVG (clipPath), PNG.
- `main.py` — прогон обеих фигур, проверки.

## Цель этого этапа
Вход — векторный PDF, где **машущая рука вынесена отдельной деталью** (сгруппирована и
физически отставлена в сторону от тела). Нужно:
1. опознать детали: тело-перёд, тело-зад, машущая(-ие) рука(-и);
2. каждую деталь провести через уже готовый конвейер: **один контур + обтравка макета по
   контуру (PowerClip) + линия реза**, в **едином масштабе фигуры**;
3. руку положить **рядом** со своей фигурой;
4. экспорт: `front.*` и `back.*` (тело + его рука рядом) в PDF/SVG + PNG-превью.

Масштабов боковой полосы, припусков, насечек и раскладки на рулон здесь НЕТ (следующие этапы).

## Вход (контракт)
- Одна страница, **векторный** PDF из Illustrator (без растра; текст — в кривые).
- Серый фоновый прямоугольник на весь лист — исключить (правило: `rect.width > 990` pt,
  как в `read_pdf.split_figures`).
- На листе разнесены детали: **тело-перёд** (левое), **тело-зад** (правое, зеркальное),
  и **машущая рука(и)** — отдельным(и) объектом(ами), НЕ перекрывающими тела.
- Тело подаётся уже БЕЗ машущей руки (осталась опущенная рука + плашка снизу).
- Если PDF растровый (есть картинки, нет векторных заливок) — остановиться и сообщить.

## Опознание деталей (алгоритм, надёжный)
Не полагаться на PDF-«группы» (pymupdf их в `get_drawings` не отдаёт). Опознавать по
**пространственному разделению**:
1. Взять все заливки, отсеять фон.
2. Собрать полигоны, `unary_union` → получить НЕСКОЛЬКО несвязных кусков (connected
   components): каждый физически отдельный объект = отдельный кусок.
3. Классификация по площади:
   - **2 самых больших куска = тела**; из них левый (меньший центр X) = перёд, правый = зад.
   - остальные значимые куски (площадь > `min_arm_area_frac` от площади тела) = **руки**.
     Мелкий мусор ниже порога — игнорировать (и залогировать, что отброшено).
4. **Пара рука↔тело**: каждую руку привязать к ближайшему телу по центроиде (левая рука → перёд,
   правая → зад). Если рук нет — просто обе фигуры без рук (не падать).
5. Опционально: если в PDF есть именованные слои OCG (`front`/`back`/`arm`) — предпочесть их;
   иначе работает пространственный способ выше.

## Масштаб (важно!)
- Коэффициент масштаба считать **по высоте тела-переда**: `s = target_height_mm / высота_тела`.
  Высота тела — вместе с плашкой (как в текущем `pieces.build_figure`).
- **Этот же `s` применить ко ВСЕМ деталям** (оба тела + все руки), чтобы рука осталась
  пропорциональной фигуре. НЕ масштабировать руку отдельно «в 2700» — она маленькая деталь.
- Тело-зад по построению той же высоты → тот же `s` (проверить, что совпадает в пределах 1 мм).

## Обработка каждой детали
Для тел и рук одинаково, переиспользуя `pieces`/`export`:
1. контур: `union → buffer(+contour_gap_close_mm).buffer(-)` → один Polygon без дыр
   (проверить `n_parts == 1`, `is_valid`);
2. обтравка оригинального вектора детали по её контуру (существующий `export.figure_pdf_content`);
3. линия реза — отдельным слоем;
4. «макет не выходит за контур» (`outside_mm2 < 1`).

## Раскладка «рядом» и экспорт
- Собрать **на фигуру** один холст: тело + его рука **рядом** (без перекрытия, зазор
  `piece_gap_mm`), в реальном относительном масштабе (общий `s`), каждая деталь обтравлена,
  со своими линиями реза.
- Экспорт: `out/front.pdf`, `out/back.pdf` (тело+рука рядом) + одноимённые `.svg` + PNG-превью.
- Дополнительно можно сохранять отдельные детали: `out/front_body.pdf`, `out/front_arm.pdf` и т.д.

## Параметры (config.yaml — дополнить существующий)
```yaml
target_height_mm: 2700
contour_gap_close_mm: 2.0        # уже есть
min_arm_area_frac: 0.02          # мин. доля площади тела, чтобы кусок считался рукой
piece_gap_mm: 100                # зазор между телом и рукой в раскладке
```

## Проверки (в консоль + тесты pytest)
- Опознано ровно 2 тела; число рук залогировано; отброшенный мусор залогирован.
- Высота обоих тел = `target_height_mm` ± 1 мм; рука масштабирована тем же `s`.
- Для каждой детали: контур один и замкнутый, `is_valid`, макет внутри контура (`outside_mm2 < 1`).
- Рука привязана к правильной фигуре (левая↔перёд, правая↔зад).
- PNG-превью каждой фигуры (тело+рука рядом) для визуальной проверки.
