# ТЗ для Claude Code — боковые части (гассет): построение и дробление на полосы

## Контекст
Проект `/opt/inflatable-cutter` (Linux, без GUI, без Corel/Blender). Переиспользовать:
- `pieces.build_figure` → контур переда (один замкнутый Polygon; зазор закрытия щелей
  считается в ФИНАЛЬНЫХ мм после масштаба к 2700 — уже сделано, `contour_gap_close_mm`);
- `export.py` (PDF `W n`/линия реза, SVG, PNG). Работаем в **финальных миллиметрах**.

## Цель
Из контура переда построить **боковую часть (гассет)** — полосу вдоль всего контура,
и **разбить её на несколько полос** (не одна длинная). Пока БЕЗ припуска на шов и БЕЗ
раскраски. Днище (низ, где вентилятор) — исключаем, это следующий этап.

## Что такое гассет (для реализации)
- Полоса идёт вдоль **контура переда по линии шитья** (одна кромка к переду, вторая к заду).
- Длина полосы = длина кривой контура; ширина = `thickness_mm` (толщина фигуры).
- **Инвариант (обязательный):** сумма длин всех боковых полос = длина(контур − днище).
  Выполняется автоматически, т.к. мы делим ОДНУ кривую на куски (длину не добавляем/убираем).

## Параметры (config.yaml — дополнить)
```yaml
thickness_mm: 170          # ширина боковой полосы = толщина фигуры (как в эталоне)
side_max_len_mm: 1500      # макс. длина одной полосы (длиннее — дорезаем)
corner_angle_deg: 35       # порог «угла» для точки разреза (поворот кривой)
corner_window_mm: 15       # окно по длине для замера поворота (устойчивость к плотным точкам)
bottom_detect_frac: 0.03   # полоса снизу для поиска нижних углов (доля высоты фигуры)
```

## Алгоритм
1. **Контур переда** (финальные мм): `pieces.build_figure` → `contour`. Внешнее кольцо
   `contour.exterior` как упорядоченная ломаная. Все длины — в мм.
2. **Найти днище и исключить:**
   - нижние точки = в пределах `bottom_detect_frac` от максимального y (низ);
   - **два нижних угла** = самый левый и самый правый среди нижних точек;
   - «кривая гассета» = дуга кольца между этими углами, идущая **вокруг фигуры (НЕ по низу)**;
   - «днище» = короткая нижняя дуга между углами (её длину тоже вывести для отчёта).
3. **Точки разреза:**
   - **углы**: вершины, где поворот кривой > `corner_angle_deg`, измеренный на окне
     `corner_window_mm` (смотреть точки на ±window по длине, а не соседние — устойчиво к
     плотным точкам после разбиения безье). Упростить кольцо (Douglas–Peucker, малый tol)
     перед замером углов допустимо.
   - обязательные точки: два конца кривой (нижние углы);
   - **добивка по длине:** идём по кривой, копим длину; если пролёт между соседними
     точками разреза > `side_max_len_mm` — вставляем промежуточный разрез каждые `side_max_len_mm`.
4. **Полосы-лекала:** каждый участок → прямоугольник `длина_участка × thickness_mm`
   (полоса режется прямой, гнётся при шитье). Пронумеровать; хранить (start_len, end_len)
   участка на кривой — для будущих насечек.
5. **Проверка инварианта:** `Σ длин участков == длина(кривая гассета)` (± 1 мм) и
   `длина(кривая) + длина(днище) == периметр контура` (± 1 мм).
6. **Отчёт в консоль:** периметр, длина днища, длина гассета, число полос, длины каждой,
   сумма, макс. длина (≤ `side_max_len_mm`).

## Экспорт (пока без припуска/цвета)
- `out/sides.pdf` / `out/sides.svg` — полосы-лекала (прямоугольники) в столбик, с подписями
  (№, длина мм).
- `out/sides_debug.png` — контур переда с **отмеченными точками разреза** и раскраской
  участков разными цветами (визуальная проверка дробления и что днище исключено).

## Структура
- `src/sides.py` (новый): `build_gusset(contour, cfg)` →
  `{curve_len, bottom_len, perimeter, segments:[{i,len,arc0,arc1}], strips:[Polygon]}`.
- `src/export.py`: добавить экспорт полос (столбик прямоугольников) + debug-подсветку.
- `main.py` (или `main_sides.py`): поток этапа боковин.
- `tests/test_sides.py`:
  - `Σ len(segments) == curve_len (±1мм)`;
  - `curve_len + bottom_len == perimeter (±1мм)`;
  - каждая полоса `len ≤ side_max_len_mm`;
  - число полос ≥ 2 (не одна сплошная);
  - все полосы шириной ровно `thickness_mm`.

## Этапность (не всё сразу)
- **ЭТАП A:** только днище + точки разреза — вывести отчёт (периметр/днище/гассет, число и
  длины полос) и `sides_debug.png` (контур с точками разреза, участки цветом, днище отдельно).
  Показать, СТОП.
- **ЭТАП B:** после подтверждения — сгенерировать полосы-лекала и экспорт `sides.pdf/svg`.

## Не входит (следующие этапы)
Припуск на шов, насечки с припуском, раскраска боковин, раскладка на рулон, деталь днища
и посадка вентилятора, боковины зада (зад = зеркало, гассет тот же).
