# ТЗ: Ручная покраска фигуры (сегментами по контуру) в дашборде

Статус: черновик к реализации (уточнён). Цель — добавить в дашборд НОВЫЙ ЭТАП после раскладки:
**«Покраска фигуры»**, где пользователь вручную красит ТОЛЬКО ГАССЕТ (боковины) отрезками по
контуру + пипеткой. Авто-варианты (кромка/доминант/R1) остаются как быстрый дефолт; ручной
режим — для точного контроля.

**ВАЖНО (уточнения заказчика):**
- Красим **ТОЛЬКО ГАССЕТ**. Перёд и зад НЕ красим и не трогаем (у них своя текстура макета).
- **Пипетка = клик по фигуре**: кликаю по части фигуры → берётся цвет этой части (из дизайна).
- **Старт с нуля** (не с авто-покрашенного).
- Отрезок контура → прилегающий к нему ГАССЕТ (может быть одна часть, две части или полчасти)
  красится в выбранный цвет.

---

## 1. Поток (UX)

1. **Детали без цвета.** После раскладки фигура/детали строятся БЕЗ покраски (контуры есть,
   заливок зон нет). Показывается этап «Покраска фигуры».
2. **Контур по периметру.** На ПЕРЕДЕ показывается цветной контур по ВСЕМУ периметру фигуры
   (как ползунок руки — интерактивная линия вдоль `gusset_line`/контура).
3. **Днище — статично.** Зона, куда пришивается днище (нижняя кромка, `g["bottom_pts"]`),
   ПОДСВЕЧЕНА другим цветом и ИСКЛЮЧЕНА из ручной покраски — её не трогаем (красится отдельно/
   авто цветом днища).
4. **Точки → отрезки.** Пользователь ставит точки на контуре: точка 1, точка 2 → отрезок [1–2].
   Дальше точка 3 → отрезок [2–3], и т.д. Точки идут по периметру последовательно.
5. **Пипетка = клик по фигуре.** Для текущего отрезка активна ПИПЕТКА — кликаю по той части
   фигуры, чей цвет хочу → берётся цвет этого места (из растра/палитры дизайна). Цвет назначается
   отрезку.
6. **Красится ТОЛЬКО прилегающий ГАССЕТ.** Гассет, прилегающий к этому отрезку контура (одна
   часть, две части или полчасти боковины — по пересечению дуг), заливается выбранным цветом.
   Перёд/зад НЕ трогаем.
7. **По кругу.** Повторять: отрезок → пипетка → цвет, пока НЕ покрыт весь периметр (без дыр,
   кроме исключённой зоны днища).
8. **Кнопка «Продолжить раскраску фигуры».** Активируется, когда периметр покрыт полностью.
   Нажатие → фигура рендерится В ЦВЕТЕ (сборка с ручными цветами) и показывается.

---

## 2. Данные и модель

- **Контур покраски** = `g["gusset_line"]` (LineString по периметру, в мм) — та же дуга, что
  уже используется для гассета (`arc0..arc1` каждой боковины). Длина = `g["gusset_len"]`.
- **Точки** пользователя: позиции вдоль контура — храним как долю периметра `t∈[0,1]` ИЛИ как
  arc-длину (мм). (x,y) для отрисовки = `gusset_line.interpolate(t·glen)`.
- **Отрезок** = `(t0, t1, color)` — дуга между двумя точками + цвет (hex).
- **Ручная покраска фигуры** = упорядоченный список отрезков, покрывающий `[0..1]` периметра
  (минус зона днища). Храним в сессии: `manual_paint: [{"t0":..,"t1":..,"color":"#rrggbb"}]`.
- **Зона днища** (исключена): интервал(ы) периметра, попадающие на `g["bottom_pts"]` →
  `dnishe_arc = (tb0, tb1)`; подсвечивается, в покраску не входит, при проверке покрытия
  считается «уже закрытой».

## 3. Маппинг отрезок → детали (как красить)

Уже есть обратная связь зона↔дуга (см. `export_pdf_grouped` `band_keys`/`_arc_on`,
`src/side_color.py` `color_sides`): каждая боковина `s` покрывает дугу `s["arc0"]..s["arc1"]`.

- Отрезок `(t0,t1,color)` → arc-диапазон `[t0·glen, t1·glen]`.
- Для каждой боковины `s`: пересечение её дуги `arc0..arc1` с arc-диапазоном отрезка → эта
  подзона боковины красится в `color` (может покрыть боковину целиком, частично «полбоковины»,
  или зацепить две соседние боковины — как доли дуги).
- **Перёд/зад НЕ красим** — у них текстура макета; ключи seam_color_bands на переде/заде в
  ручном режиме не обязательны (опционально оставить дим-ключ для сборки).
- Итог: вместо авто-`color_sides` формируем `s["bands"]` боковин из ручных отрезков.

**Реализация бэка:** флаг/вход `manual_paint` в cfg. В `color_sides` (или перед ним): если
`cfg["manual_paint"]` задан — строить `s["bands"]` НЕ сэмплингом, а нарезкой ручных отрезков по
`arc0..arc1` каждой боковины. Днище-зону пропускаем.

## 4. UI (дашборд, Flask + canvas)

- Новая страница/панель «Покраска фигуры» (по аналогии с резом руки — `dashboard/` канвас,
  точки в PT, см. [[web-dashboard]]).
- Канвас: фон = превью переда (`front_preview.png`), поверх — линия контура (`gusset_line` в PT),
  маркеры точек, подсветка текущего отрезка, подсветка зоны днища (серым/штрихом).
- Клик по контуру → добавить точку (снэп к ближайшей точке `gusset_line`).
- После 2-й точки — активна ПИПЕТКА: следующий клик по изображению макета берёт цвет пикселя
  (canvas getImageData) → назначается текущему отрезку; отрезок заливается превью-цветом.
- Список отрезков сбоку (номер, цвет, t0–t1), можно править/удалять.
- Индикатор покрытия периметра (%). При 100% (минус днище) — кнопка «Продолжить раскраску
  фигуры» активна.
- «Продолжить» → POST `manual_paint` на бэк → пересборка (export_pdf_grouped с `manual_paint`)
  → показ цветной фигуры/лекал.

**API (ориентир):**
- `GET /api/paint_contour/<sid>` → точки контура (PT) + зона днища + габариты превью.
- `POST /api/paint/<sid>` {segments:[{t0,t1,color}]} → сохранить + пересобрать → вернуть layout.png.

## 5. Интеграция с существующим кодом

- `src/side_color.py color_sides`: ветка `if cfg.get("manual_paint"): bands из отрезков` (новая
  функция `_bands_from_manual(s, manual, bottom_arc)`), иначе — текущий авто-путь.
- `export_svg.build_layout`: прокинуть `manual_paint` в cfg (ничего не ломает — деф. нет).
- `dashboard/app.py`: новый роут + _build_cfg прокидывает `manual_paint` из сессии.
- Днище-зона: вычислить arc-интервал `bottom_pts` на `gusset_line` (проекция точек низа на
  периметр) — исключить из покраски и из проверки покрытия.
- Пипетка-палитра: можно переиспользовать `design_palette` (готовые логические цвета дизайна)
  как быстрый выбор рядом с пипеткой.

## 6. Решено (ответы заказчика) + остаётся уточнить

**Решено:**
- Красим ТОЛЬКО гассет; перёд/зад не трогаем.
- Пипетка = клик по фигуре → цвет той части (из дизайна). Старт с нуля. Зад не красим.

**Остаётся уточнить:**
1. **Пипетка: точный пиксель или снэп к палитре?** Клик даёт точный цвет пикселя, или
   снэпить к логической палитре дизайна (`design_palette`) — чище для печати/CMYK?
2. **Зона днища** — полностью исключить из контура, или дать отдельную «одну кнопку цвета днища»?
3. **Точки: свобода или снэп** — кликать точку в любом месте контура, или снэп к «углам»/
   переходам?
4. **CMYK** — пипетка сразу в краски материала (связано с задачей CMYK, ждём набор красок).
5. «Есть ещё дополнительные» — жду остальные пункты заказчика, допишу.
