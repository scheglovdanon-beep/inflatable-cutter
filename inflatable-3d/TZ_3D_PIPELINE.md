# ТЗ: Пайплайн «2D лекала → 3D надувная фигура»

Версия 1.0. Проект `/opt/inflatable-3d` (3D) поверх `/opt/inflatable-cutter` (2D раскрой).
Назначение: из векторного PDF-макета плоской рекламной надувной фигуры (перёд+зад+рука)
получить **надутую 3D-модель** (GLB), собранную ТОЛЬКО из реальных лекал пайплайна, сшиванием.

## 0. Принципы
- 3D собирается **только из деталей 2D-пайплайна** (`export_svg.build_layout`): перёд, зад,
  боковины-гассет, рука (база→плечо→предплечье→кисть), днище+ножка. Ничего не выдумывать.
- Любое новое поведение — под флагом конфига/ENV; дефолты не ломают старые фигуры.
- Геометрию проверять **визуально** (рендер PNG), «зелёный лог» без картинки не принимать.

## 1. Вход
- `macet.pdf` — векторный макет (перёд обязательно; зад реальный или зеркало; рука в силуэте).
- `config_<name>.yaml` — параметры фигуры (из cutter): `target_height_mm` (2700),
  `expected_arms`, `make_back`, `make_base`, `arm_template`, пороги детекта руки,
  mem-флаги (`union_batch_size:300`, `raster_zoom:1.5`, `arm_raster_z:3.0`).

## 2. Этапы (канонический поток)
Единый оркестратор: `./build_figure.sh <pdf> <config> <name>`.

### Этап 1 — 2D панели + текстуры (venv cutter)
`scripts/export_panels.py <pdf> --config <cfg> --name <name>` → `output/<name>/`:
- `panels.json`: `body{contour_ring, bbox_mm, faces(триангуляция крышки СТРОГО по контуру),
  front_tex, back_tex, gusset[]{width,color}}`, `arm{chain[baza,plecho,predplechie]{grid,
  rolled,r_bot,r_top,h,fill}, hand{contour,gusset_w,texture}, mounts[{armpit_mm,tip_mm}],
  hole_r_mm}`, `base{fan_d,leg_w,leg_h}`.
- `front.png/back.png` — ВЕКТОРНЫЕ текстуры (cairosvg, не растр: растр давал тёмные зоны),
  `hand.png` — текстура кисти.
- Проверка: `texture_view.py <pdf> --config <cfg> -o layout.png` — 2D-раскладка всех лекал.

### Этап 2 — триангуляция кисти
`scripts/handbuild.py <name>` → `output/<name>/hand_build.json`:
`{contour, faces(shapely-триангуляция внутри полигона), straight_i(самый длинный сегмент =
прямой срез-запястье), W(gusset_w), n}`.

### Этап 3 — ТЕЛО (герметичный надутый баллон)
`generate.py -- output/<name>/panels.json` с ENV:
`NO_SPINE=1 NO_HOLE=1 MATERIAL=nostretch TENSION=120 SHEAR=90 BEND=0 PRESSURE=6 GRAVITY=0`.
- `make_inflatable`: перёд (faces) + зад + стена-гассет (ширина/цвет из `gusset[]`) =
  **замкнутая** оболочка; перёд на −Y, камера −Y (без зеркал).
- **Тело НЕ дырявим** (`NO_HOLE=1`) → держит давление само.
- Cloth+Pressure → надув → bake → `output/<name>/model.glb`.

### Этап 4 — РУКА (цельная) + СВАРКА с телом
`FIG=<name> blender -b --python scripts/weld_figure.py` → `output/<name>_figure/model.glb`.

## 3. ЛОГИКА РУКИ (ключевое)
### 3.1 Детект и лекала
Машущая рука детектится в 2D-пайплайне (рез от подмышки, детект кисти по профилю ширины).
Экспорт даёт ЦЕПОЧКУ раскатанных реальных деталей: **база(Ø250) → плечо(Ø250→Ø140) →
предплечье(Ø140→Ø100) → кисть(срез, периметр = верхнее кольцо предплечья)**.
Каждая деталь-труба = раскатка развёртки (`grid` = кольца U×V, V=64).

### 3.2 Сборка руки в ОДНУ деталь (`arm_onepiece.py`)
Все стыки — **кольцо-к-кольцу по совпадающим диаметрам**, сварка вершина-в-вершину:
- база↔плечо (Ø250), плечо↔предплечье (Ø140), предплечье↔кисть (Ø100 ↔ срез).
- `weld_rings(A,B)`: сдвинуть кольцо B на кольцо A (матч по 3D-расстоянию, перебор offset+dir),
  затем `remove_doubles` сварит совпавшие вершины.
- Кисть: «подушка» перёд+зад (триангуляция) + боковина-W по кривой кромке; прямой срез
  открыт и дроблением (`subdivide_edges`) приводится к 64 вершинам, матчится по углу к
  кольцу предплечья и сваривается напрямую (round↔slot раскрывается).
- Заглушка ТОЛЬКО у монтажного торца базы (Ø250) → рука замкнута.
- **Проверка: `boundary edges == 0`** (водонепроницаемо = одна деталь).

### 3.3 Ориентация кисти
Кисть ПРОДОЛЖАЕТ предплечье: `up=Tt` (ось руки), `face=−Y` (ладонь вперёд), срез у запястья,
ладонь вытянута наружу. (Для «палец вверх» — `up=+Z`; выбирается под позу фигуры.)
ВАЖНО: `Rh=np.array([up,face,side]).T @ np.array([h_up,h_face,h_side])` — второй множитель
БЕЗ `.T`, иначе ладонь уходит вбок.

### 3.4 Надув кисти (частая ошибка!)
Плоская крышка кисти триангулирована ТОЛЬКО по контуру → внутри нет вершин, давлению нечего
выпячивать → кисть не надувается. Фикс: `subdivide_edges(cuts=1,use_grid_fill=True)` ПЕРЕД
cloth (вершины внутрь) + лёгкая растяжимость (`tension≈120`, не 2000) → кисть раздувается в подушку.

### 3.5 СВАРКА руки с фигурой (две камеры давления, соединены)
Модель: **тело — свой баллон (своё давление), рука — свой баллон (своё давление), соединены
в один меш в месте плеча.** Тело НЕ дырявим (иначе травит/boolean крошит гассет в не-манифолд).
Алгоритм (`weld_figure.py`):
1. Построить руку (`arm_onepiece`), надуть, перенести к подмышке (`Taff`: монтажное кольцо базы
   `ba[0]` → точка подмышки, ось руки `Am` → `ex=d_out` наружу, доворот вокруг оси).
2. Импорт тела (герметичного); склеить дубли вершин glTF (`remove_doubles 5e-4`).
3. **Точка стыка = вершина поверхности тела, БЛИЖАЙШАЯ к контурной точке руки `holeP`**
   (фильтр по X и Z(высота) у подмышки → `min(dist to holeP)`). Это место на гассете, что на
   2D-лекале отведено под руку. (НЕ «самая наружная» вершина — она уходит вниз = стык слишком низко.)
4. Репозиция руки: центр кольца базы → точка стыка минус `d_out*0.03` (перекрытие ~3см).
5. `join` в один объект → рука входит в поверхность тела без зазора.
   (Вершинный merge НЕ применять — на мелкой сетке он схлопывает соседние вершины.)
- Результат: цельный меш, рука на уровне подмышки, два объёма воздуха (перегородка = заглушка
  базы + стенка тела).

## 4. МАТЕРИАЛ / ФИЗИКА
- Oxford 135 с пропиткой = матовый (roughness 0.88), нерастяжимый. Cloth:
  `tension/comp≈120` (лёгкая растяжимость для надува плоских панелей/кисти), `shear≈90`,
  **`bend=0`** (без рёбер жёсткости), `gravity=0`, `pressure` 6–12.
- Цвета деталей — из `fill` лекала (рукав белый, предплечье/кисть — кожа); материал рендерится
  на обе стороны. Кисть — текстура `hand.png` на перёд и зад.
- **НАДУВ ТРЕБУЕТ ЗАМКНУТОЙ оболочки** (иначе давление не держится). Любые вырезы — только
  ПОСЛЕ надува; плоские крышки надуваются только при наличии внутренних вершин (subdivide).

## 5. ГРАБЛИ (проверено болью)
- Вырез отверстия boolean'ом по квад-гассету → **не-манифольд обод без петли** → варить не к чему.
  Вырез ПОСЛЕ надува промахивается (надутый гассет смещается от плоской точки). ⇒ тело не дырявим,
  рука входит в поверхность с перекрытием (п.3.5).
- glTF-импорт ДУБЛИРУЕТ вершины на швах → ложные границы; всегда `remove_doubles` после импорта.
- `subdivide_edges`/`remove_doubles` инвалидируют python-ссылки на BMVert → кольца помнить по
  index, перефетчить после.
- Вершинные цвета (color_attributes) роняют Blender headless → цвета материалами.
- Днище-ножка пока отдельный баллон; делать тем же приёмом (входит в дно с перекрытием).

## 6. ВЫХОД
`output/<name>_figure/model.glb` — надутая 3D-фигура (тело+рука одной деталью).
Просмотр: дашборд `/3d/<name>_figure` (model-viewer).
