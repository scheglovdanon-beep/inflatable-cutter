# Веб-дашборд раскроя (админка)

Повторяет чат-воркфлоу в браузере: загрузка PDF-макета → выбор размера и числа рук →
разметка реза руки → разметка запястья/локтя → сборка полной раскладки (PDF/SVG).

## Запуск
```bash
cd /opt/inflatable-cutter
venv/bin/pip install flask          # один раз
venv/bin/python dashboard/app.py    # http://127.0.0.1:5000
```

## Шаги
1. **Макет** — загрузить векторный PDF. Страница рендерится для выбора точек (всё в координатах PT страницы).
2. **Параметры** — размер фигуры (1700/2700/3300/4200), число машущих рук (0/1/2), для 2 рук — «руки одинаковые».
3. **Рез руки** — при входе бэкенд **авто-детектит** руку(и) (`detect_armpits`) и предлагает точки:
   корень (у подмышки), кончик, хорду реза (`blade_perp`). Можно поправить любую точку кликом или
   сменить режим: «хорда» (2 точки) / «вертикальный» (1 точка, рез вверх от корня). Рез проверяется
   бэкендом (`cut_waving_arms`) — при ошибке покажет её.
4. **Кисть/предплечье** — на изолированной руке отметить срез запястья (2 точки) и локтя (2 точки).
5. **Раскладка** — сборка (2–5 мин, фоновая). Превью + скачать PDF и SVG (группы под CorelDRAW).

## Как это устроено
- Все точки — в **PT страницы PDF** (как `manual_arms` в конфигах). Клик → `PT = пиксель/zoom + page.rect.x0`.
- Базовый конфиг на размер = проверенный `config_cosmo{size}.yaml` (универсальные дефолты + память-оптимизации);
  в него подставляются выбор пользователя (`expected_arms`, `arms_identical`) и точки (`manual_arms`).
- Сборка идёт тем же единым входом `export_pdf_grouped.py` (через `run_capped.sh`, cgroup-лимит памяти).
- Сессии (загрузки/выходы) — в `dashboard/sessions/<id>/` (в git не коммитятся).

## Ограничения MVP
- Авто-детект рук пока не выведен в UI (рез — ручной по точкам, как в чате). Легко добавить кнопку
  «определить автоматически» (вызов `detect_armpits`/`detect_arms_v2`).
- Один пользователь/процесс; dev-сервер Flask. Для продакшена — gunicorn/uwsgi.
